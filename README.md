# MNC-EMPLOYEE-DATA-ANALYSIS
Human Resource Data

## Objective  
The HR Data Analytics project aimed to analyse employee and organisational data to uncover actionable insights related to workforce demographics, income distribution, job roles, and organisational structure.  

The goal was to evaluate patterns in employee characteristics, including age, gender, salary, tenure, and department, to support data-driven HR decision-making. This project demonstrates how HR data can be transformed into meaningful insights for talent management and workforce strategy.

## Project Steps  

### 1. Data Collection and Understanding  
The dataset includes employee-level information such as:  
- Age, Gender  
- Monthly Income  
- Job Role & Department  
- Education Level  
- Marital Status  
- Work Location  

It also includes company-level data like industry, country, and employee count.
